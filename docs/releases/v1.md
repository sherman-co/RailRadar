## RailRadar v1 — first release

RailRadar watches Iranian train ticket sites and notifies you on **Bale** or **Telegram** the moment seats open up.

### Download
Download **RailRadar-windows.zip**, extract it, and double-click `RailRadar.exe`. The control panel opens in your browser at `http://127.0.0.1:8080`.

### Features
- **Live web panel**: updates without refreshing; light, dark and automatic themes; works on phone screens.
- **Works with any ticket site**: Alibaba, Flytoday, Raja, MrBilit, Safarmarket, Samtik, Utravs, Snapptrip, Tikban and others that list trains with a time and a price.
- **Parallel checks**: all searches are checked at the same time every 2.5–3.5 minutes (configurable).
- **Smart alerts**: notifies only when at least N seats are free (default 2), once per train; it alerts again only if the train fills up and reopens.
- **Trains only**: buses and combined train + bus trips are ignored.
- **Filters**: watch a single train by number (e.g. `328`) or departure time (e.g. `17:30`).
- **Bale and Telegram bot**: start/stop, check now, list searches, toggle or delete each search, change minimum seats, and add a new search just by sending a link.
- **Saves mobile data**: tabs stay open and only refresh, images are not loaded, and a data-usage meter is shown in the panel.
- **Detects Raja system outages**: recognizes each site's "rail system unavailable" message and shows when it is expected back.
- **No setup needed**: uses Microsoft Edge when its own browser is missing; settings are saved in `%APPDATA%\TicketBot` and survive updates.
