## RailRadar v3 — much lighter on CPU and RAM

### Download
Download **RailRadar-windows.zip**, extract it over your previous folder, and run `RailRadar.exe`. Your settings and searches are kept.

### Improvements
- **Near-zero CPU between checks.** Ticket sites keep running animations and timers even when nobody is looking. RailRadar now pauses each page's JavaScript after a check and resumes it right before the next refresh. The tab stays open. In tests with 4 sites, idle CPU dropped from about 155% to about 3%.
- **New low-RAM mode** (Settings → low-RAM mode). Closes the tabs between checks while keeping the site files in the disk cache. In tests with 4 sites, Chrome memory dropped from about 956 MB to about 356 MB, with each check only a few seconds slower.
- **Lighter browser.** GPU, extensions, sync and background updates are turned off.
- **New name: RailRadar.** The version is now shown in the panel header.

### Features
Everything from v1 and v2: live panel, any ticket site, parallel checks, minimum-seat alerts, trains-only filter, Bale and Telegram control, data saving, outage detection, and accurate Raja and MrBilit parsing.
